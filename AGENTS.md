# AGENTS.md

Compact guidance for working in this repo. Skip anything the repo already makes obvious.

## What this is
Google AI Studio applet (Gemini) deployed to Cloud Run. `metadata.json` declares `MAJOR_CAPABILITY_SERVER_SIDE_GEMINI_API`. AI Studio injects `GEMINI_API_KEY` and `APP_URL` at runtime (see `.env.example`); do not hardcode them. `server.js` is generated by the AI Studio build pipeline, not present in source — `npm run clean` deletes it.

## Commands
- `npm run dev` — Vite dev server on `0.0.0.0:3000` (`--host`).
- `npm run build` — `vite build`.
- `npm run lint` — typecheck only (`tsc --noEmit`). There is NO eslint/prettier/formatter and NO test suite.
- `npm run clean` — removes `dist/` and `server.js`.

## Toolchain quirks
- **Tailwind v4 + daisyUI v5** are wired via the `@tailwindcss/vite` plugin and CSS only (`src/index.css`: `@import "tailwindcss"; @plugin "daisyui";`). There is NO `tailwind.config`/`postcss.config`. Do not add PostCSS-based Tailwind setup.
- **Path alias** `@/*` maps to repo root (set in both `vite.config.ts` and `tsconfig.json`). Import app code as `@/...`.
- **HMR is intentionally disabled** when `DISABLE_HMR=true` (AI Studio sets this to stop flicker during agent edits). Leave `vite.config.ts` server/HMR block alone.
- **Two lockfiles exist**: `bun.lock` and `package-lock.json`. Confirm the active package manager before installing deps so you don't desync the lockfile.

## Architecture (non-obvious)
- Single-page React app, no router. Entry: `src/main.tsx` → `src/App.tsx`.
- Global UI state (year, weekStart, markedDays, monthRange, position pickers) lives in the **zustand** store `src/store/useCalendarStore.ts`. Components read via that hook; imperative updates inside callbacks use `useCalendarStore.getState()`.
- Holidays load from the external **Nager.Date API** (`src/services/holidayApi.ts`), not Gemini. Spanish country/region name maps live there.
- Core domain logic: `src/utils/calendarHelper.ts` (`generateYearData`). UI is print-targeted A4 landscape (`src/index.css` `@media print` + `.page-a4`); `.no-print` hides chrome when printing/exporting PDF.
- Calendar shape: `MarkedDaysMap` keyed `M-D` (`monthIndex+1-day`), defined in `src/types.ts`.

## Conventions
- UI strings and code comments are **Spanish**. Keep new user-facing text and comments Spanish.
- `lucide-react` for icons; `motion` available for animation.
- Print/PDF output must stay A4 landscape and preserve the `.no-print`/`.page-a4` rules.
